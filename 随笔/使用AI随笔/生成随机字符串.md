`HUIFU_CREDENTIAL_ENCRYPTION_KEY` 不是从汇付后台获取的，而是我们自己生成的数据库加密主密钥，用于加密保存汇付 RSA 私钥。

建议生成方式：

```bash
openssl rand -base64 48
```

它会生成约 64 个字符的随机字符串。将完整输出作为环境变量：

```bash
HUIFU_CREDENTIAL_ENCRYPTION_KEY='生成的随机字符串'
```

注意：

- 测试、预发布、生产环境分别生成，不要共用。
- 同一生产环境的两个 PM2 实例必须使用完全相同的值。
- 不要写入 Git、代码、SQL 或普通配置文件；应配置在云效的加密变量/密钥管理中。
- 首次写入汇付配置后，不能随意更换或丢失，否则已有私钥密文无法解密。
- 当前代码要求至少 32 个字符，并会通过 SHA-256 派生实际的 AES-256 密钥：[huifuCredentialCrypto.ts](/Users/lixingjuan/Documents/lzh/lzh-convoy/lzh-backend/src/utils/huifu/huifuCredentialCrypto.ts)。

配置到云效后，`ecosystem.config.cjs` 已经负责把变量传给两个 PM2 实例。可以用下面的方式确认“是否存在”，但不要打印密钥内容：

```bash
test -n "$HUIFU_CREDENTIAL_ENCRYPTION_KEY" && echo configured
```
